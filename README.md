# 🦞 Boujee Boil — Order Manager

A lightweight, mobile-responsive web application designed for managing restaurant orders, generating receipts, tracking sales daily, and handling delivery logistics offline or online.

---

## ✨ Features

* **Order Creation & Customization**: Quickly build customer orders with preset menu items, sauces, add-ons, and custom instructions/notes.
* **Delivery Address Tracking**: Dedicated delivery address field captured for orders and printed exclusively on kitchen tickets.
* **Dual Print System**:
  * **Customer Receipt**: Includes customized branding, embedded golden crab logo, itemized bill, subtotal, delivery fees, discounts, and total.
  * **Kitchen Ticket**: Clean, high-visibility ticket formatted for back-of-house staff featuring the customer's phone number, delivery address, ordered items, and special notes.
* **Offline First**: Runs completely inside the browser using standard web technologies. Orders are automatically saved to browser local storage.
* **Accounting Export**: One-click **Export Accounting CSV** button to download full order histories formatted for spreadsheets (Excel, Google Sheets, Numbers).
* **Daily Dashboard**: Real-time overview of order counts, total daily sales, and pickup vs. delivery stats.
* **Mobile Friendly**: Designed to fit desktop screens as well as iOS/Android mobile devices with built-in mobile print support.
